What am I seeing?

All three tracking inputs use the same root-weighted triad templates and position-and-tempo filter. “Bass + horns” pools their currently sounding MIDI notes into one harmonic observation before tracking. A shared MIDI key counts once; different octaves remain separate. This is simple note pooling, with no learned instrument weights. Horns are tested as harmonic evidence, without written-melody or lick matching. With no active notes in the selected input, the clock continues without a harmonic update. Switching inputs selects a separate run from the start; it does not transfer the other follower's state.

The summary scores cover all 200 ms checks, including silences. “Evidence present” is the fraction of checks with active selected notes, not a confidence or accuracy score. All versions start at the known first bar with the same supplied tempo and untimed chord plan.

For each check, the beat difference is converted to milliseconds using the average reference tempo of the current annotated bar. The mean absolute error averages these converted errors across all checks. This is an approximate time equivalent of the position error; it is not processing latency or an independently annotated millisecond measurement. Conversion changes only the display, not the tracker or its saved results.

This is the existing exploratory harmonic follower, not a reproduction of the complete Yamaha system. The MIDI itself is automatically transcribed; “ground truth” refers to annotated position.
