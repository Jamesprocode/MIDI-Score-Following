What am I seeing?

All followers start at the known first bar with the written (catalog) tempo and the untimed chord plan, and see only piano notes up to the current moment. Harmony: binary key activity against triad templates. Network: the beat/downbeat-phase TCN trained on synthetic Lakh performances (Maezawa 2023 recreation). Rule-based onset cue: the earlier onset-phase heuristic (beat phase only).

For each check, the beat difference is converted to milliseconds using the average reference tempo of the current annotated bar; this is a time equivalent of the position error, not processing latency.

The piano MIDI is recorded, not transcribed; bass and drums are dataset MIDI for listening only. “Ground truth” refers to annotated bar positions.
